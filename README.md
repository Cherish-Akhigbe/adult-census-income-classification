# Adult Census Income Classification

## Project Overview
This project explores census data to understand income patterns, investigate factors associated with income levels, and explore population segments using machine learning techniques.

## Objectives
- Explore demographic and income patterns.
- Query and analyze data using SQL.
- Clean and preprocess data for analysis.
- Apply K-Means clustering to identify population segments.

## Tools & Technologies
- Python
- Pandas and NumPy
- SQL and SQLite
- Data visualization
- Scikit-learn

## Project Workflow
1. Data extraction and storage in SQLite.
2. Exploratory data analysis (EDA).
3. Data cleaning and preprocessing.
4. SQL queries and insight generation.
5. K-Means clustering and cluster evaluation.
6. PCA-based visualization and cluster interpretation.

## Key Learning Outcomes
This project provided practical experience in data preparation, SQL-based analysis, exploratory analysis, unsupervised learning, and interpreting data-driven patterns.
